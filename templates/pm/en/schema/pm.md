# Project-management rules

For running projects across many conversations. Runs alongside the base rules; this page wins on conflict.

- `wiki/decisions/`: one decision per page named `YYYY-MM-DD-topic.md` with context / options / decision / rationale / consequences / status. Never delete a reversed decision; change its status and link the new one.
- Meeting notes go to `raw/sources/` (`source_type: meeting`, `date`, `attendees`). Extract decisions, todos ([[todo]]) and open questions from them.
- `wiki/todo.md` is a checkbox list with owner and due date.
- At the end of a session, ask: "Any new decisions or todos to write back?"
